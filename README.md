# 💙 HeartSync

Aplicação desenvolvida em equipe durante a graduação em Ciência da Computação.

O projeto tem como objetivo aplicar conhecimentos de desenvolvimento de software na construção de uma aplicação utilizando Flutter.

## 🛠️ Tecnologias

- Flutter
- Dart
- SQLite
- Git
- GitHub

## 👨‍💻 Minha contribuição

Minha participação no projeto foi concentrada principalmente na **estruturação e implementação do banco de dados**.

Entre as atividades realizadas:

- Modelagem da estrutura de dados;
- Definição das tabelas necessárias para a aplicação;
- Implementação do armazenamento local utilizando SQLite;
- Estruturação das operações necessárias para persistência dos dados;
- Integração da camada de dados com a aplicação.

> O projeto foi desenvolvido em equipe e as demais funcionalidades foram implementadas pelos outros integrantes.

## 📚 Aprendizados

A participação no HeartSync me permitiu desenvolver conhecimentos práticos sobre:

- Modelagem de bancos de dados;
- Persistência de dados em aplicações Flutter;
- SQLite;
- Integração entre aplicação e banco de dados;
- Desenvolvimento colaborativo com Git e GitHub.

## 🤝 Trabalho em equipe

O HeartSync foi desenvolvido de forma colaborativa. Minha contribuição esteve principalmente relacionada à **camada de dados**, enquanto outras partes da aplicação foram desenvolvidas pelos demais integrantes.
